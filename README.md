# 🎵 Spotify Clone

A fully functional **Spotify-inspired music player** built using **HTML, CSS, and JavaScript**.  
This project focuses on **frontend development**, **audio handling**, and **dynamic UI updates** without any frameworks.

---

## 🚀 Features

- **Play / Pause Songs** – Control music playback easily.  
- **Next & Previous Track** – Navigate between songs seamlessly.  
- **Dynamic Playlist** – Click any song to play instantly.  
- **Albums & Songs** – Automatically fetches songs from folders with album cover, title, and description.  
- **Live Song Time & Seek Bar** – Shows current time / total duration with clickable seek bar.  
- **Volume Control** – Adjustable volume slider with Mute/Unmute.  
- **Responsive UI** – Works on desktop and mobile with hamburger menu.  
- **Clean Track Names** – Displays readable song names automatically.

---

## 🛠 Technologies Used

- HTML5 – Structure  
- CSS3 – Styling & responsiveness  
- JavaScript (ES6) – Logic & interactivity  
- Font Awesome – Icons  
- Audio API – Music playback
